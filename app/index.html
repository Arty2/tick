Manual

Acari

Acari is a countdown timer, the successor to /tick. People use it to keep time during talks, live streams, meetings and stage events. It can be installed, and works without the internet.

Live: acari.vercel.app · Source: github.com/Arty2/tick · Website: heracl.es/tick

Dialectic Acheiropoieton of Heracles Papatheodorou and Claude

Mouse and touch

  • Click or tap to start. Click again to pause, and again to start.
  • In overtime, a click loads the next session, or resets the timer if the queue is empty.
  • Click or tap the list under the timer to open the queue.
  • Double-click or double-tap to turn kiosk mode on or off.
  • While running, the mouse wheel adds or takes away 1 minute.
  • While running, swipe 👆 to add 10 minutes, 👇 to take away 5, 👈 to add 1, 👉 to take away 1.

Keyboard

  • Enter starts again from the starting length. Space starts or pauses.
  • Type 0–9, then Enter, to set the length in minutes.
  • Ctrl+Enter loads the next session now. It waits until it is started.
  • ↑ adds 10 minutes, ↓ takes away 5, ← adds 1, → takes away 1.
  • Ctrl+↑ and Ctrl+↓ load the previous or next preset.
  • N opens the queue. U opens the target time. W opens the warnings.
  • Delete or Backspace changes the session name.
  • ` rings the bell. Insert turns the bell at the end on or off.
  • Page Up turns kiosk mode on or off. Page Down changes the theme.
  • End resets. Home opens this manual. Tab opens the menu.
  • Esc closes the menu or a window. If none is open, it leaves target time, clock mode or kiosk mode.

Colours

  • Grey — not started.
  • White — running.
  • Orange — first warning (2 minutes left, or 5 for sessions over 10 minutes).
  • Flashing orange — second warning (1 minute left, at first).
  • Amber — paused.
  • Red — overtime. The time has run out, and the timer counts up.
  • Green — just reset.
  • Purple — the next session is loaded.
  • Blue — counting down to a time of day.
  • Teal — clock mode.

Warnings

  • The warn button (or W) sets two warning points, in seconds.
  • At the first warning the numbers turn orange. It comes 2 minutes before the end, or 5 minutes before the end of a session longer than 10 minutes. A number typed in the box is used instead; leaving the box empty goes back to this.
  • At the second warning the numbers also flash. At first this is 60 seconds (1 minute) before the end.
  • Setting a warning to 0 turns it off. The settings are saved.

Kiosk mode

  • Kiosk mode hides the buttons and the menu. Only the time and the top line are shown.
  • Turn it on with the kiosk button, Page Up, or a double-click. Turn it off the same way, or with Esc.
  • On computers it also fills the screen and keeps the screen from going dark. On iPhones and iPads the address bar stays.

Presets

  • There are five presets in the menu. Click one to load it.
  • Hold a preset down, or right-click it, to change its name and length. An empty preset shows +.
  • Holding down reset for about one second removes everything Acari has saved.

Queue

  • The queue is a list of sessions that run one after another. Open it with queue, the list under the timer, or N.
  • Each session has a name and a length in minutes, or a time of day written @14:30 to count down to it. + Add adds one, × removes one, and dragging a row changes the order.
  • As text (in a link or the remote's queue box), sessions are separated by |: Talk:25|Break:5|Panel@14:30. A | in a name is written \|.
  • When a session ends, the next one starts by itself. Ctrl+Enter loads it sooner.

Target time

  • The target button (or U) counts down to a time of day, in the 24-hour clock. If that time has passed today, it counts down to tomorrow.

Clock mode

  • The clock button shows the time of day instead of the timer. The timer keeps running, and the queue keeps moving.
  • A click, or the timer button, shows the timer again.

Remote control

  • The remote button shows a six-letter code and a QR code. Scan the code on another device to get a remote pad. Or, on that device, open Acari, choose remote, then Join, type the code and choose Remote. This screen then changes to kiosk mode, and stays in it if the remote disconnects. While a session is on, the menu button reads remote: waiting or remote: connected.
  • Any number of remote pads can control one timer. A pad shows +1, +2… in its top bar for the other pads connected. The top bar also shows the code; typing another one there switches to that timer.
  • The remote pad shows the time left and the queue. Its buttons reset, start or pause, ring the bell, load the next or the previous session, and change the time. Before the start, the minute buttons change the length to count down from, and Reset is greyed out. On phones the buttons vibrate.
  • Black covers this screen in the background colour while the timer runs on underneath; changes from the remote pad stay hidden until it is pressed again. Esc, a double tap or a double-click here also lifts it.
  • Its queue box holds the current queue. Change it and press Set; an empty box clears the queue.
  • A message typed on the remote pad appears on this screen for 6 seconds, on an orange band above the time. The time gets smaller while it shows. Clear removes it sooner.
  • A timer can show on more than one screen. The small screen button (🖥️) on the remote pad shows a link and QR code for another kiosk; so does remote, Join, Kiosk on the other screen. The extra kiosk is read only: it follows the first one and takes no input. A double-click fills its screen; Esc makes it an ordinary timer again.
  • If the first kiosk stops answering, the remote pad says Kiosk lost, and after a few seconds a read-only kiosk takes over and continues the timer. A new kiosk opened from the pad's link does the same.
  • The timer doesn't stop when this screen is lost: the remote pad keeps counting, and its buttons work on its own copy. When this screen answers again, it takes the pad's timer. If the pad itself was offline, it takes this screen's timer instead.
  • Tabs in the same browser connect without the internet. Different devices need the internet to find each other, through a service called PeerJS. This may not work on some school or office networks.

Install

  • The install button adds Acari to this device as an app, in its own window. Where the browser has no install window of its own, the button says where to find it in the browser's menu.
  • Installed or not, once Acari has been opened it opens again without the internet.

Share

The share button opens the device's share window with a link to the timer as it is now. Where there is no share window, it copies the link. Opening the link sets up the same timer. The settings follow a # in the link, so they are not sent to the server. They are used for that visit only; they do not replace the saved settings.

Param Value Description
mins 1–999 The starting length in minutes.
label text The session name shown under the timer.
next Title:25|10 The queue. Sessions are separated by |; each is name:minutes (Talk:25), only minutes (25), or a countdown to a time of day (Panel@14:30): Keynote:40|Break:5|Lunch@12:30. A | in a name is written \|.
theme dark | light The theme.
sound 0 | 1 The bell when the time runs out: 0 off · 1 on.
remote XXXXXX A six-letter remote code. The page opens as a remote pad instead of a timer. The remote button makes these links.
kiosk XXXXXX A six-letter remote code. The page opens as a kiosk for that code: read only while another kiosk holds the timer, or taking the timer over if none does. The small screen button on the remote pad makes these links.

Example:
#mins=25&label=Keynote&next=Break:5|QA:10&theme=dark&sound=1
