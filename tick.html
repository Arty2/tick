Manual

/tick

/tick is a countdown timer. People use it to keep time during talks, live streams, meetings and stage events. It is one file and works without the internet.

Live: acari.vercel.app · Source: github.com/Arty2/tick · Website: heracl.es/tick

Dialectic Acheiropoieton of Heracles Papatheodorou and Claude

Mouse and touch

  • Click or tap to start. Click again to pause, and again to start.
  • In overtime, a click loads the next session, or resets the timer if the queue is empty.
  • Click or tap the list under the timer to open the queue.
  • Double-click or double-tap to turn kiosk mode on or off.
  • While running, the mouse wheel adds or takes away 1 minute.
  • While running, swipe 👆 to add 10 minutes, 👇 to take away 5, 👈 to add 1, 👉 to take away 1.

Keyboard

  • Enter starts again from the starting length. Space starts or pauses.
  • Type 0–9, then Enter, to set the length in minutes.
  • Ctrl+Enter loads the next session now. It waits until it is started.
  • ↑ adds 10 minutes, ↓ takes away 5, ← adds 1, → takes away 1.
  • Ctrl+↑ and Ctrl+↓ load the previous or next preset.
  • N opens the queue. U opens the target time. W opens the warnings.
  • Delete or Backspace changes the session name.
  • ` rings the bell. Insert changes the sound setting.
  • Page Up turns kiosk mode on or off. Page Down changes the theme.
  • End resets. Home opens this manual. Tab opens the menu.
  • Esc closes the menu or a window. If none is open, it leaves target time, clock mode or kiosk mode.

Colours

  • Grey — not started.
  • White — running.
  • Orange — first warning (2 minutes left, or 5 for sessions over 10 minutes).
  • Flashing orange — second warning (1 minute left, at first).
  • Amber — paused.
  • Red — overtime. The time has run out, and the timer counts up.
  • Green — just reset.
  • Purple — the next session is loaded.
  • Blue — counting down to a time of day.
  • Teal — clock mode.

Warnings

  • The warn button (or W) sets two warning points, in seconds.
  • At the first warning the numbers turn orange. It comes 2 minutes before the end, or 5 minutes before the end of a session longer than 10 minutes. A number typed in the box is used instead; leaving the box empty goes back to this.
  • At the second warning the numbers also flash. At first this is 60 seconds (1 minute) before the end.
  • Setting a warning to 0 turns it off. The settings are saved.

Kiosk mode

  • Kiosk mode hides the buttons and the menu. Only the time and the top line are shown.
  • Turn it on with the kiosk button, Page Up, or a double-click. Turn it off the same way, or with Esc.
  • On computers it also fills the screen and keeps the screen from going dark. On iPhones and iPads the address bar stays.

Presets

  • There are five presets in the menu. Click one to load it.
  • Hold a preset down, or right-click it, to change its name and length. An empty preset shows +.
  • Holding down reset for about one second removes everything /tick has saved.

Queue

  • The queue is a list of sessions that run one after another. Open it with ▶ queue, the list under the timer, or N.
  • Each session has a name and a length in minutes. + Add adds one, × removes one, and dragging a row changes the order.
  • When a session ends, the next one starts by itself. Ctrl+Enter loads it sooner.

Target time

  • The target button (or U) counts down to a time of day, in the 24-hour clock. If that time has passed today, it counts down to tomorrow.

Clock mode

  • The clock button shows the time of day instead of the timer. The timer keeps running, and the queue keeps moving.
  • A click, or the timer button, shows the timer again.

Remote control

  • The remote button shows a six-letter code and a QR code. Open the link or scan the code on another device to get a remote pad. This screen then changes to kiosk mode, and stays in it if the remote disconnects.
  • The remote pad shows the time left and the queue. Its buttons reset, start or pause, ring the bell, load the next or the previous session, and change the time. On phones they vibrate.
  • Its queue box holds the current queue. Change it and press Set; an empty box clears the queue.
  • A message typed on the remote pad appears on this screen for 6 seconds, on an orange band above the time. The time gets smaller while it shows. Clear removes it sooner.
  • If this screen stops answering, the remote pad says Kiosk disconnected. The small screen button (🖥️) next to its status shows a link and QR code for a new screen, which continues the timer.
  • Two tabs in the same browser connect without the internet. Two devices need the internet, and connect through a service called PeerJS. This may not work on some school or office networks.

Share

The share button copies a link to the timer as it is now. Opening the link sets up the same timer. Settings in a link are used for that visit only; they do not replace the saved settings.

Param Value Description
mins 1–999 The starting length in minutes.
label text The session name shown under the timer.
next Title:25,10 The queue. Each session is name:minutes (Talk:25) or only minutes (25), separated by commas: Keynote:40,Break:5,10. A comma inside a name is written \,.
theme dark | light The theme.
sound 0 | 1 | 2 0 off · 1 a bell at the end · 2 a bell every minute of overtime.
rc XXXXXX A six-letter remote code. The page opens as a remote pad instead of a timer. The remote button makes these links.
host XXXXXX A six-letter remote code. The page opens as a new timer screen for that code and continues the timer. The small screen button on the remote pad makes these links.

Example:
?mins=25&label=Keynote&next=Break:5,QA:10&theme=dark&sound=1
